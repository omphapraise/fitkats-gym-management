# Fit Kats Sandton — Gym Management System

Fit Kats Sandton is a premium tiered-membership gym management system, built
for the Sandton flagship branch. This repository contains the web front-end
covering the public marketing site, the member portal, and the staff/management
dashboard, developed as part of the XISD6329/W Work Integrated Learning module.

## Overview

Fit Kats Sandton offers four membership tiers (Student, Middle Class, Premium,
Elite) and a 32-feature digital system spanning member management, payments,
class booking, tier perks, loyalty, progress tracking, facility maintenance,
crowd/capacity management, and AI-driven coaching.

This project implements the core member-facing and staff-facing web interface
for that system.
